# Terms of Service (Пользовательское соглашение)

## Описание
Одна страница `/terms` с полным текстом Пользовательского соглашения (включая Политику обработки персональных данных). Контент организован в аккордеон по разделам документа.

## Роутинг
- `app/terms/layout.tsx` — обёртка в ClientLayout (шапка + футер)
- `app/terms/page.tsx` — страница с аккордеоном

## Компоненты
- **components/ui/Accordion.tsx** — на основе `@radix-ui/react-accordion` с иконкой `ChevronDown` из `lucide-react`
- **features/terms/ui/TermsPage.tsx** — контент страницы: текст соглашения, разбитый на секции-аккордеоны

## Футер
